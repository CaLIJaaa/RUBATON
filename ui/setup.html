Настройка Tenderly

Подготовка тестового RUBA / USDT

Вставьте данные нового форка Ethereum mainnet. Приложение развернёт RUBA и хранилище, пополнит ваш кошелёк и подготовит ликвидность.

Сервер запускается один раз командой npm run tenderly. Следующие форки можно подключать на этой странице.

Первичная подготовка может занять несколько минут. Ход выполнения появится ниже.

Подготовка нового форка обычно занимает 2 транзакции: если лимит 20 ещё не использован, останется 18 для тестирования. Точный режим подготовки появится в ходе выполнения. Повторный запуск подготовленного этим способом форка с тем же кошельком не отправляет новых транзакций.

Новый форк

Скопируйте Admin RPC из Tenderly. Он нужен серверу для выдачи тестовых токенов. Приватный ключ вашего кошелька не нужен.

Admin и Public RPC должны относиться к одному форку. Используйте отдельный Chain ID, например 73571, а не Ethereum mainnet 1.

На этот адрес поступят тестовые ETH, RUBA и USDT. Он также получит доступ к обмену и пулу.

Суммы токенов и начальная ликвидность

При первой подготовке баланс кошелька пополнится до указанных сумм. Начальная ликвидность создаётся один раз для нового рынка.
